# מעקב תזונה בהריון — דאשבורד אישי

דף אחד עצמאי (`nutrition.html`) שמתפרסם כ-**Artifact פרטי ב-claude.ai**.
נבנה מהמקורות ב-`src/` באמצעות `python build_nutrition.py`.

> **פרטיות:** התיקייה הזו מכילה רק קוד גנרי — מאגר מזון כללי, טבלאות DRI,
> מנוע חוקים וממשק. **אסור להכניס לכאן נתונים אישיים** (תוספים, מתכונים,
> בדיקות, פרופיל). הנתונים האישיים חיים אך ורק במסד הנתונים של ה-Artifact
> (יכולת `db`) ובמטמון הדפדפן של המשתמשת.

## מה בפנים

| קובץ | תפקיד |
|---|---|
| `src/page.html` | שלד הדף (RTL, טאבים, מסך נעילה) עם placeholders |
| `src/styles.css` | עיצוב: tokens לשני ערכות נושא, mobile-first |
| `src/app.js` | state, סנכרון `db` ↔ localStorage, נעילה, חישובים, כל הטאבים |
| `src/chat.js` | טאב ההתייעצות ופענוח טקסט חופשי דרך יכולת `sample` |
| `src/charts.js` | גרפי SVG ידניים (מפת חום, מגמה, דירוג, לוח היענות) |
| `src/data/foods.js` | ~150 מזונות ישראליים, ערכים ל-100 גרם (USDA / משרד הבריאות, משוער) |
| `src/data/targets.js` | יעדי DRI להריון לפי טרימסטר, UL, טווחי עלייה במשקל (IOM) |
| `src/data/rules.js` | חוקים דקלרטיביים: בדיקות/אבחנות → התאמת יעדים + הערות |
| `build_nutrition.py` | מאחד הכול ל-`nutrition.html` ובודק שאין כתובות חיצוניות |

## איך זה עובד

- **אחסון:** `claude.use("db")` — אוספים `settings`, `supplements`, `foods`,
  `days` (מסמך ליום), `labs`, `diagnoses`, `chat`. כשהיכולת לא זמינה
  (פתיחה מקומית) הדף עובד על localStorage בלבד ומציג "מצב מקומי".
- **סיסמה:** hash (SHA-256 + salt) ב-`settings/profile`; נעילה אוטומטית
  אחרי 10 דקות ללא פעילות.
- **צ'אט:** `claude.use("sample")` — ההודעה נשלחת עם סיכום מחושב של היום,
  הפרופיל והבדיקות, רק בלחיצה על "שלחי". אין מפתח API ואין שירות חיצוני.
- **גיבוי:** `claude.use("downloads")` לייצוא JSON; ייבוא דרך בחירת קובץ.
- **אפס פניות רשת:** אין CDN, אין גופנים חיצוניים, הגרפים ב-SVG.

## פיתוח

```bash
cd nutrition
python build_nutrition.py        # → nutrition.html
node --check src/app.js          # בדיקת תחביר
```

לפרסום: כלי ה-Artifact עם `capabilities: {db: {}, sample: {}, downloads: true}`.
עדכון = בנייה מחדש + פרסום לאותו נתיב קובץ (אותה כתובת).
